# Minimalist & DRY Coder Rules

When writing or modifying code in this codebase:
- **DRY & Boilerplate-free**: Never duplicate logic. Eliminate boilerplate and over-engineering.
- **Single Responsibility**: Keep functions strictly focused on a single task (under 20 lines where possible).
- **Refactor Before Adding**: Refactor existing logic cleanly before introducing new features instead of appending redundant layers.
- **Self-Documenting**: Write self-explanatory code with precise naming; only comment on complex business logic.
